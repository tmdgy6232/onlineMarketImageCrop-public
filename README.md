# onlineMarketImageCrop

엑셀에 적힌 상품코드를 읽어, 쇼핑몰에서 각 상품의 **대표이미지**와 **상세이미지**를
자동으로 수집·가공해 파일로 저장한다.

## 결과물

상품코드 1개당 2개 파일이 생성된다.

| 파일 | 사양 |
|---|---|
| `{상품코드}_main.jpg` | **600 × 600** 고정. 자르지 않고 비율 유지 리사이즈 후 흰 배경 중앙 배치 |
| `{상품코드}_detail.jpg` | 가로 **750** 고정, 세로 가변. 맨 위에 양식, 그 아래로 상세 컷을 위→아래 순서로 이어붙임 |

상세 이미지가 JPEG 높이 한계(65,535px)를 넘으면
`_detail_01.jpg`, `_detail_02.jpg` … 로 분할 저장된다.

### 상세 상단 양식

상세이미지 맨 위에 상품명·모델명이 적힌 양식이 붙는다.

- 상품명: 상품 페이지에서 가져온다
- 모델명: 상품코드의 `_` 를 공백으로 바꾼 값 (`411E4TI604_BK` → `411E4TI604 BK`)

양식 파일은 글자가 비어있는 이미지를 쓰고, 그 위에 글자만 얹는다.
양식 디자인 자체는 건드리지 않는다.

| 설정 (`config.py`) | 설명 |
|---|---|
| `HEADER_ENABLED` | 양식을 붙일지 여부. `False` 면 상품 컷만 이어붙인다 |
| `HEADER_TEMPLATE_PATH` | 글자가 비어있는 양식 이미지 경로 |
| `HEADER_NAME_BAND` / `HEADER_CODE_BAND` | 상품명·모델명을 그릴 세로 구간 `(y0, y1)` |
| `HEADER_CENTER_X` / `HEADER_TEXT_MAX_WIDTH` | 글자의 가로 중심과 최대 폭 |
| `HEADER_FONT_PATH` | 글꼴 (기본: 맑은 고딕 Bold) |

양식 디자인을 바꾸면 위 좌표만 다시 잡으면 된다.
상품명이 길면 글자 크기가 자동으로 줄어들고, 양식 아래쪽 순백 여백은 잘라낸다.

## 설치

```bash
python -m pip install -r requirements.txt
```

> **`pip` 가 아니라 `python -m pip` 을 쓸 것.**
> PC에 Python이 두 벌 설치돼 있으면 `pip install` 이 다른 인터프리터에 설치돼서
> `pip list` 에는 보이는데 `import` 는 실패하는 일이 생긴다.
> `python -m pip` 은 실행할 인터프리터와 같은 곳에 설치한다.

확인:

```bash
python -c "import requests, PIL, openpyxl, tqdm; print('ok')"
```

## 실행

```bash
python main.py samples/input_sample.xlsx
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `--site NAME` | 기본 사이트 지정 |
| `--out DIR` | 출력 루트 폴더 변경 (기본값 `output`) |
| `--limit N` | 앞에서 N건만 처리 |
| `--delay SEC` | 상품 간 고정 딜레이. 미지정 시 0.5~1초 랜덤 |
| `--verbose` | 디버그 로그 출력 |

### 종료 코드

| 코드 | 의미 |
|---|---|
| `0` | 전건 성공 |
| `1` | 입력 파일 없음 / 처리할 상품코드 없음 |
| `2` | 실행은 끝났으나 실패한 상품이 있음 |

`2` 는 정상 동작이다. 품절·삭제 상품이 섞여 있으면 여기로 끝난다.
어느 상품이 왜 실패했는지는 `result.xlsx` 의 오류메시지 열에 있다.

## 입력 엑셀 형식

A열에 상품코드, B열에 사이트. 1행은 헤더다.
빈 행과 앞뒤 공백은 무시하고, 중복 코드는 건너뛴다.

| 상품코드 | 사이트 |
|---|---|
| ABC123_WH | bucketstore |

**사이트 컬럼을 넣는 것을 기본으로 한다.** 상품코드만으로는 어느 사이트 상품인지
판별할 수 없기 때문이다. 컬럼이 없으면 전부 기본 사이트로 처리하면서 경고를 남기는데,
이때 다른 몰 상품이 섞여 있으면 "품절/삭제 추정" 으로 잘못 기록된다.

바로 실행 가능한 예시가 `samples/input_sample.xlsx` 에 있다.

## 출력

```
output/
  20261006_165908/
    221D3SV289_WH/
      221D3SV289_WH_main.jpg      600x600
      221D3SV289_WH_detail.jpg    750 x 가변
    result.xlsx                   성공/실패 리포트
    log.txt
```

실행할 때마다 타임스탬프 폴더가 새로 생긴다. 기존 결과를 덮어쓰지 않는다.

`result.xlsx` 컬럼: 상품코드 / 사이트 / 상태 / 대표이미지 / 상세이미지 장수 /
최종 상세 높이(px) / 오류메시지
